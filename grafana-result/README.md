# 손으로 받은 그라파나 캡처

`loadtest-snapshot.sh` 가 생기기 전에 사람이 브라우저에서 받은 것이다.

**어느 회차의 것인지 파일명으로 가릴 수 없다.** 이름에 대시보드 번호와 렌더 시각만 붙어 있다.
세 장의 렌더 시각은 2026-09-28 09:59 에서 10:10 UTC 이고, 같은 날 버전 비교 회차는 07:21 에서
09:18 UTC 에 돌았다. **즉 회차가 끝난 뒤에 받은 것이고 회차 구간을 담고 있지 않다.**

그래서 수치의 근거로 쓰지 않는다. 그날 대시보드가 어떤 모양이었는지 보여 주는 용도다.

**회차 캡처는 `docs/coupon/rounds-<날짜>/` 에 있다.** 그쪽은 `loadtest-snapshot.sh` 가 회차
구간(`--from`/`--to`)을 지정해 받은 것이라 어느 회차의 어느 구간인지가 정해져 있다.
