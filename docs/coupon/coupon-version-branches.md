# 버전 비교 브랜치

**v4 는 이미 채택안이다.** 이 브랜치들은 그 결정을 뒷받침할 실측을 만들기 위해 있고
병합 대상이 아니다. 설계와 근거는 [coupon.md](coupon.md) 6장에 있다.

| 브랜치 | 버전 | v4 에서 무엇을 뺐나 |
|---|---|---|
| `perf/coupon-v1` | v1 | Redis 순번과 큐와 벌크 INSERT 를 다 뺀다. `coupon.issued_quantity` 조건부 UPDATE 하나로 판정한다 |
| `perf/coupon-v2` | v2 | 큐와 벌크 INSERT 를 뺀다. Redis 순번은 쓰고 요청 스레드가 직접 INSERT 한다 |
| `perf/coupon-v3` | v3 | 가상 스레드를 뺀다. 나머지는 v4 와 같다 |
| `main` | v4 | 채택안 |

## 왜 브랜치로 하나

`main` 에 병합하면 운영이 잠시 v4 보다 나쁜 구현으로 돈다. 그래서 `deploy.yml` 의
`workflow_dispatch` 로 브랜치에서 바로 이미지를 만들어 띄운다.

태그가 커밋 SHA 이고 ECR 이 `IMMUTABLE` 이라 버전마다 태그가 달라 서로 덮지 않는다.

## 회차를 무효로 만드는 조건

**이걸 미리 정하지 않으면 나중에 유리한 회차만 고르게 된다.**

| 조건 | 왜 |
|---|---|
| 워밍업 설정이 버전 사이에 다르다 | 실측에서 껐을 때 3.313초, 켰을 때 0.302초다. 10배가 갈린다 |
| `k6_dropped_iterations_total` 이 0 이 아니다 | 부하가 안 들어갔다 |
| 회차 중 `up` 이 0 이 된다 | 인스턴스가 죽었다 |
| 버전당 회차가 3 미만이다 | 같은 설정이 0.302초에서 0.518초로 흔들린 이력이 있다 |

## 합격 판정에 쓰는 값

[coupon.md](coupon.md) 7장이 정한 그대로다. **`k6_coupon_settled_duration_p99`** 를 쓴다.

`k6_http_req_duration_p99` 를 쓰면 안 된다. 혼잡(503)이 요청 예산을 태우고 끊기므로
**예산을 줄이는 것만으로 그 값이 내려간다. 앱은 하나도 안 빨라졌는데도 그렇다.**

두 값을 다 싣고 그 간격을 셋째 정보로 본다. 벌어져 있으면 혼잡이 많다는 뜻이다.

## 커넥션 풀

v1 과 v2 는 요청 스레드가 트랜잭션을 연다. v4 의 "발급 요청 0" 이 성립하지 않아 풀을 2 로
두면 풀 대기가 곧 병목이 된다.

**2026-09-26 에 RDS 에서 `max_connections` 를 60 으로 실측했다.** `resource-budget.md` 가
추정치로 적어 둔 값과 같다. 부하 중 다른 출처가 앱 3대 24, 배치 2, `mysqld_exporter` 3,
운영자 2 로 31 을 쓰고 29 가 남는다. 전용 3대에 나누면 인스턴스당 9 이고, 앱과 같은 8 로
잡으면 3대 24 에 총합 55 로 60 안에 든다.

| 브랜치 | `maximum-pool-size` | 왜 |
|---|---:|---|
| v1, v2 | 8 | 예산에서 나눠 받는다. 둘을 같게 두어 차이가 순번 위치 하나가 된다 |
| v3, v4 | 2 | 요청 스레드가 트랜잭션을 안 연다. 플러시 하나와 캐시 적재 하나뿐이다 |

**내가 고른 값을 재는 것이 되지 않게 예산에서 나오는 값을 썼다.** v1 과 v2 가 커넥션과 락에
부딪히는 것은 측정의 잡음이 아니라 결과다. v3 가 "DB 왕복이 준다" 를 얻고 v5 가 "커넥션이
인스턴스 수와 무관해진다" 를 얻는 근거가 바로 그 벽이다.

## v1 에만 있는 차이 둘

**409 와 410 이 갈리지 않는다.** v1 은 미확정 순번이라는 상태가 없어 소진이 곧 최종이다.
v2 부터는 `pending` 키를 쥔 사람이 있으면 그 번호가 다시 나올 수 있어 둘이 갈린다.

**순번 확보와 발급 기록이 한 트랜잭션이다.** 조건부 UPDATE 가 잡은 락을 커밋까지 쥐고 있어야
남이 같은 번호를 못 받는다. 나누면 UPDATE 를 커밋한 뒤 INSERT 가 실패할 때 그 번호가 결번이
되고 재고가 줄어든 채 발급은 안 된 상태가 남는다.
